# Built by Yousef

A drawing register of Yousef's architecture projects. Each project opens full-screen from the front page.

- `index.html` is the register (front page).
- Each project lives in `projects/<name>/`.
- Plain files, no build step. Published with GitHub Pages from the `main` branch.

Furniture models and textures in `projects/another-one/models/` are CC0 assets from Poly Haven.
